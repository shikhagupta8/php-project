# 🌐 Simple 3-Page Bootstrap + PHP Website

This is a beginner-friendly web development project built using **HTML, Bootstrap, and PHP**. It includes three main pages: a Home page, a Registration page, and a Login page with basic backend handling using PHP.

---

## 📌 Features

* 🏠 **Home Page**

  * Responsive layout using Bootstrap
  * Navigation bar with links to Register and Login
  * Clean UI

* 📝 **Registration Page**

  * User registration form
  * Built with Bootstrap components
  * Handles form data using PHP (POST method)

* 🔐 **Login Page**

  * Login form with email and password
  * Basic PHP authentication logic (no database / optional database)

---

## 🛠️ Technologies Used

* HTML5
* Bootstrap 5
* PHP
* CSS3 (optional customization)
* JavaScript (optional validation)

## 🚀 How to Run the Project

### 🖥️ Requirements

* Install XAMPP / WAMP / LAMP server
* PHP installed

### ▶️ Steps

1. Clone the repository:

   ```
   git clone https://github.com/Shikha/php.git
   ```

2. Move the project folder to:

   * `htdocs` (for XAMPP)
   * `www` (for WAMP)

3. Start Apache server from control panel.

4. Open browser and run:

   ```
   http://localhost/project-folder/
   ```
